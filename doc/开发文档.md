# Prompt Next 开发文档

简体中文 · [English](development.en.md) · [繁體中文](development.zh-TW.md)

## 产品范围

Prompt Next 是一个本地优先的桌面提示词管理器，**AI 绘画库优先，人设库并列保留**。用于收藏、整理、复制和备份提示词与参考图。项目采用 Go、Wails v3、Vue 3、TypeScript、Naive UI、Vite 和 SQLite。应用提供两个可删除的示例条目，目标发布平台为 macOS Apple Silicon 与 Windows x64。桌面菜单支持 macOS ⌘N／⌘F 和 Windows Ctrl+N／Ctrl+F，正常窗口的尺寸和位置保存在本机。

## 功能要求与验收

| 区域 | 要求与当前行为 |
| --- | --- |
| 品牌和窗口 | 产品名为 **Prompt Next**。使用选定的红、蓝、黄错位照片 Logo，应用窗口、首页、关于、macOS Dock 和 Windows 图标使用同一品牌。工作台是小房子，人设库是小鱼，三个导航图标底色一致。 |
| 工作台 | 启动先显示首页，AI 绘画库在大肥鱼人设库之前。浅色横幅右侧显示 Logo。首页显示两库数量、最近更新、图片与数据库占用、数据目录和近 14 天新增图片面积图，以及绘画分类、AI 模型两张饼图。左下角用「本地数据」描述存储。 |
| 浏览和查找 | 默认卡片，首张参考图作为封面，可切换到三栏列表，保存视图偏好。搜索标题、中英文正文、说明、标签、分类、负向提示词、生成参数与模型。可按当前库的分类、收藏、标签和模型筛选，并按创建时间、更新时间或标题排序。 |
| 绘画条目 | 使用弹框新建与编辑。字段有标题、参考图、分类、逗号分隔标签、多个 AI 模型、中英文提示词、创建和更新时间。中文或英文至少填一种。说明、负向提示词和参数备注放在「更多字段」。分类和标签各占一行，模型下拉支持搜索和三列多选。 |
| 人设条目 | 独立维护人设提示词、标题、分类、标签、作者、说明和时间。支持旧大肥鱼人设数据导入。 |
| 条目操作 | 支持收藏、编辑、删除、复制为新条目、单条 Markdown 导出。中英文和负向提示词可分别复制。可填写双花括号变量、按条目保存命名预设，并一次复制渲染后的中文、英文和负向提示词。多选支持批量收藏、取消收藏、改分类、删除和导出，删除后可在 24 小时内撤销。删除确认使用「取消 / 删除」，详情关闭按钮有边框，条目日期使用本地时间 `YYYY-MM-DD HH:mm:ss`。离开有改动的编辑弹框前提示确认。 |
| 参考图 | 多选 PNG、JPEG、GIF、WebP。编辑弹框里可放大预览、拖动排序，或用左右按钮移动。已保存图片和新图片可混排。卡片封面使用首图的缓存缩略图（长边最多 400 像素），详情可放大原图。每条最多 24 张，每张不超过 12 MB、6400 万像素，单次新增图片合计不超过 40 MB。 |
| 偏好设置 | 左侧分为「外观」「AI 模型」「分类」「标签」「数据管理」「关于」。浅色、深色、跟随系统与卡片／列表切换即时生效。两库有独立的默认分类，自定义分类可新增、改名和删除。删除分类会保留条目并移至未分类。标签可按库查看使用数量、改名或合并，并从侧栏按标签聚合浏览。内置模型从配置加载，自定义模型可新增、改名、删除。改名或移除仅影响选择列表，已保存条目的历史名称仍可搜索。数据管理可直接打开文件夹，提供导入、备份与未引用图片清理。关于保留作者 GitHub。 |
| 界面一致性 | 参考 Tiny RDM 的紧凑交互，输入框、搜索、按钮和弹框采用小圆角，并提供聚焦、悬停、按下和选中反馈。首页使用浅色背景和内嵌 SVG 导航图标。 |
| 导入与恢复 | 兼容旧人设 JSON、旧管理台收藏及应用备份。导入预览区分新增、重复与无效记录，普通导入跳过重复项。完整双库备份可在确认后覆盖恢复，覆盖前自动保存安全快照。 |

图片趋势按本机文件保存日期统计，同一图片的重复引用只计一次。备份恢复时新写入的文件计入恢复当天。分类图按绘画条目计数，模型图中多选条目分别计入每个模型。

## 工程分层

```text
main.go                         启动 Wails、注册服务、嵌入前端和图标
internal/
  desktop/                      Wails 接口与原生文件对话框、剪贴板、浏览器
  library/                      提示词模型、SQLite、图片、备份、设置与统计
    image-models.json           内置 AI 模型
    testdata/                   合成测试数据
  fileio/                       共享的原子文件写入
frontend/
  src/                          Vue 界面、图表、主题和工作区状态
    composables/                 筛选、图片编辑与导入流程
  public/icons/                  应用与库的公开图标
  bindings/                     Wails 生成的 TypeScript 调用层
build/                           系统图标、平台配置、打包脚本
doc/                             多语言文档、教程与 GitHub 发布信息
```

`main.go` 负责组装依赖。桌面接口负责打开目录、文件选择、剪贴板等系统交互，库层负责校验和数据读写。Go 模块名为 `github.com/Daneliya/prompt-next`。改变服务签名后运行 `wails3 generate bindings -clean=true -ts -i` 或重新执行 Wails 构建，使用生成结果替换旧绑定。

## 数据、兼容与发布

- 用户数据保存在系统配置目录下的 `prompt-next`。macOS 通常为 `~/Library/Application Support/prompt-next`，Windows 通常为 `%AppData%\prompt-next`。首次启动新版前请退出旧版，程序会在新目录不存在时迁移 `PromptManager` 或 `prompt-manager`。如果新目录已存在，就使用新目录并保留旧目录。应用中的「打开文件夹」会定位实际目录。
- `prompts.db` 保存两库、设置与待撤销的删除记录。SQLite 使用 WAL 和 5 秒 `busy_timeout`，按 `user_version` 在事务中逐版向上迁移。旧版单模型值仍可读为单项列表。自定义模型从旧 `custom-image-models.json` 迁入设置，旧文件保留。内置模型仍由 [模型配置](../internal/library/image-models.json) 提供。
- `images/<编号>/` 保存该条目的原图，`thumbnails/<编号>/` 保存缩略图。旧库升级时会自动分目录迁移已引用图片。跨条目使用同一张图片时，每个条目目录保存自己的副本。「设置 → 数据管理 → 查看未被引用的图片」列出缩略图、实际文件名和大小。确认后重新检查引用，仍被条目或 24 小时撤销记录使用的文件会保留。
- JSON 备份 v3 包含双库、收藏、编号、引用图片、主题、视图及展示字段、自定义分类和模型、变量预设。v1/v2 仍可恢复并保留现有设置。普通导入和选中导出用于合并。覆盖前将当前双库及设置保存到 `backups/`，快照失败会中止覆盖。便携备份与安全快照上限 128 MB。更大的库可退出应用后复制整个数据目录。窗口状态留在本机的 `window.json`。
- 旧人设原始资料属于应用之外的输入。本仓库只保留合成测试样例。

开发使用 `wails3 dev`。在项目目录运行 `wails3 task lint` 和 `wails3 task test`。GitHub Actions 在 macOS 运行前端类型检查和构建、`go vet`、`go test`。应用「关于」和 macOS／Windows 打包版本读取 `build/config.yml` 的 `info.version`。 macOS 打包执行 `wails3 task darwin:package:dmg`，Windows 打包执行 `wails3 task windows:package ARCH=amd64`。Windows 安装器需要 NSIS。安装包在 `bin/`，适合上传至 GitHub Releases。对外发布前在目标系统检查安装、首次启动及升级保留数据，并按分发需要完成签名与公证。 [Wails macOS 打包](https://wails.io/guides/build/macos/) · [Wails Windows 打包](https://wails.io/guides/build/windows/)

发布验收重点是双库切换、中英文编辑及复制、图片顺序和封面、跨语言搜索、旧人设与带图备份恢复、模型与分类配置、系统文件夹入口和升级保留数据。
