# Prompt Next 开发文档

## 产品范围

Prompt Next 是一款本地优先的桌面提示词管理器，包含文本、绘画、视频提示词库和大肥鱼人设库。采用 Go、Wails v3、Vue 3、TypeScript、Naive UI、Vite 和 SQLite，面向 macOS Apple Silicon 和 Windows x64。每个库各提供一条可删除的示例。

## 功能要求与验收

| 区域 | 要求与当前行为 |
| --- | --- |
| 品牌和窗口 | 应用名为 **Prompt Next**。窗口、首页、关于及平台应用图标使用红、蓝、黄错位照片 Logo。工作台用小房子，人设库用小鱼，导航图标使用统一底色。支持 macOS ⌘N／⌘F 和 Windows Ctrl+N／Ctrl+F，保存正常窗口的尺寸与位置。 |
| 工作台 | 首页依次显示文本、绘画、视频、大肥鱼人设库。横幅用浅色背景及应用 Logo。显示四库数量、最近更新、数据库和附件占用、当前数据目录、近 14 天新增提示词折线面积图及绘画分类与模型分布。趋势按本地创建日期统计仍在库的条目，每条计一次。调整创建时间会移动对应的统计日期。分类图按绘画条目计数，模型图按每个选中的模型分别计数。右下角状态栏每 5 秒刷新应用主进程内存占用和系统物理内存总量。 |
| 浏览和查找 | 默认卡片，可切换三栏列表和瀑布流。卡片和列表可配置标题、正文、模型、编号、时间等字段。瀑布流悬停时放大封面并展示浅色渐变信息层。搜索标题、中英文正文、说明、编号、作者、标签、分类、负向提示词、参数和模型。支持收藏、分类、标签、模型筛选和时间、标题排序。搜索框随窗口伸缩，筛选框采用固定宽度，分类和排序比标签及模型更窄。侧栏分隔当前库、按标签聚合及分类。 |
| 文本和人设 | 文本库直接显示正文。人设库维护角色提示词，支持导入旧大肥鱼人设数据。可填写分类、标签、原作者和说明。 |
| 绘画条目 | 支持中英文、负向提示词、生成参数和多个模型。标题必填，中文或英文至少填一种。至少上传一张效果图，首张用于封面。可另附原始参考图片。分类、标签分别占一行。模型下拉支持查找及多列选择，长模型名省略显示。 |
| 视频条目 | 至少附加一段效果视频，可另附原始参考图片。一条最多附加 12 段 MP4／WebM，单段不超过 64 MB，单次新增合计不超过 192 MB。首段视频画面用于卡片和瀑布流封面。详情逐段显示缩略图和大小，弹窗可切换上一段和下一段。macOS 优先使用系统媒体框架生成封面。 |
| 新建、编辑与详情 | 使用弹框，提示词区可折叠，保存按钮固定在底部。原作者名称和链接位于表单底部。新建和编辑都可在「条目时间」填写创建、更新时间。新建留空时自动记录，编辑时清空创建时间保留原值，更新时间留空记录本次保存时间。日期以本地时间 `YYYY-MM-DD HH:mm:ss` 展示。详情顶部在六位编号前显示库名，操作按钮靠右，底部操作栏固定。新编号从 100001 起，旧编号保留。关闭有改动的表单前确认。 |
| 图片 | 多选 PNG、JPEG、GIF、WebP。可拖动排序或用前移、后移按钮调整。首图使用缓存缩略图作封面。详情缩略图下显示大小，弹窗显示原图、文件名、分辨率、大小及格式，并支持左右切换。效果图与参考图片合计每条最多 48 张，每张不超过 12 MB、6400 万像素，单次新增图片合计不超过 80 MB。 |
| 合集 | 合集入口进入卡片页，空时显示空状态。弹窗支持填写名称、说明并选取成员。同一套提示词的变体可跨库关联，删除合集保留成员条目。 |
| 复制、导出与回收站 | 支持收藏、编辑、复制为新条目、单条 Markdown 导出和双花括号模板变量。可保存命名变量预设，分别复制中文、英文或负向内容，也可一次复制全部渲染结果。多选可批量收藏、取消收藏、改分类、删除和导出。左下角回收站支持 24 小时内单条或批量恢复，也可彻底删除。 |
| 偏好设置 | 左栏区分外观、AI 模型、分类、标签、数据管理、关于。支持浅色、深色、跟随系统及简体中文、English，默认简体中文。中文空下拉显示「无数据」。绘画与视频模型各自配置。绘画内置 GPT Image 2.6 和 Muse Image，视频内置 Seedance 各版本、Muse Video 等。可在设置切换提示词库后分别添加、改名和删除自定义模型。旧自定义模型归入绘画配置，历史条目上的模型名保留。分类可按库添加、改名、删除，删除后原条目移至未分类。标签可统计数量、重命名和合并。关于保留作者 GitHub。 |
| 数据管理 | 可打开实际数据文件夹、切换到已有库或用空目录初始化新库，也可恢复默认目录。切换确认后重启，原目录数据保留。未引用图片清理先列出缩略图、文件名和大小，再确认。导入可预览新增、重复和无效项。完整备份覆盖恢复前自动保存安全快照。 |

## 工程分层

```text
main.go                         启动 Wails、注册服务、嵌入前端和图标
internal/
  desktop/                      Wails 接口、原生文件对话框、剪贴板和浏览器
  library/                      提示词、SQLite、附件、备份、设置和统计
    image-models.json           绘画模型配置
    video-models.json           视频模型配置
    testdata/                   合成测试数据
  fileio/                       共享的原子文件写入
frontend/
  src/                          Vue 界面、图表、主题、语言和工作区状态
    composables/                筛选、图片编辑和导入流程
  public/icons/                 应用和库图标
  bindings/                     Wails 生成的 TypeScript 调用层
build/                          系统图标、平台配置和打包脚本
doc/                            简体中文开发文档、教程、发布信息和截图
```

Go 模块名是 `github.com/Daneliya/prompt-next`。桌面层封装系统交互，库层负责校验和读写。修改绑定后运行 `wails3 generate bindings -clean=true -ts -i`，或由 Wails 构建重新生成。

## 数据与兼容

- 默认数据目录为 macOS 的 `~/Library/Application Support/prompt-next` 或 Windows 的 `%AppData%\prompt-next`。默认目录不存在时可迁移旧 `PromptManager` 或 `prompt-manager`。语言和数据目录选择存于应用配置，窗口状态保存在 `window.json`。
- `prompts.db` 保存条目、合集、设置和回收站记录。SQLite 使用 WAL 和 5 秒 `busy_timeout`，通过 `user_version` 逐版迁移。条目时间写入统一 UTC 格式，界面和首页趋势按本地时间处理。旧单模型字段仍可读取，旧自定义模型文件会迁入数据库设置。
- `images/<编号>/` 和 `videos/<编号>/` 保存各条目的附件，`thumbnails/<编号>/` 保存缩略图。跨条目重复使用附件时各自保存副本。清理会重新检查引用，保留在库或仍可恢复的记录正在使用的图片。
- 完整 JSON 备份包含四个库、收藏、编号、合集、引用附件、自定义分类和模型、主题、视图和变量预设。包含参考图片的备份使用 v8。其余备份按内容使用 v7 或 v5，仍兼容 v6 单视频备份。旧条目的图片和视频继续作为效果素材读取。恢复较老格式时会保留该格式尚未包含的库或设置。
- 覆盖恢复前写入 `backups/`。快照失败会中止覆盖。JSON 备份上限 128 MB，更大的库可在退出应用后复制整个数据目录。应用仓库中的示例和截图使用演示资料。

## 本地开发与打包

准备 Go 1.26+、Node.js 24、npm 和 Wails v3。macOS 需要 Xcode Command Line Tools，Windows 运行需要 WebView2。环境的命令行及手动安装步骤见 [开发教程](开发教程.md)。

在项目根目录运行以下命令。

```bash
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
wails3 doctor
wails3 dev
```

如果终端找不到 `wails3`，把 Go 的可执行文件目录加入 `PATH`。首次运行会安装前端依赖并生成绑定。

```bash
wails3 task lint
wails3 task test
wails3 build
```

GitHub Actions 在 macOS 运行前端类型检查、构建、`go vet` 和 `go test`。应用「关于」和安装包的版本读取 `build/config.yml` 中的 `info.version`。

| 安装包 | 命令 |
| --- | --- |
| macOS Apple Silicon DMG | `wails3 task darwin:package:dmg` |
| Windows x64 NSIS | `wails3 task windows:package ARCH=amd64` |

在具备对应工具链的系统运行命令，Windows 安装器需要 NSIS，产物在 `bin/`。发布前检查四库切换、中英文、时间编辑和趋势、视频封面与播放、图片预览、回收站、合集、带附件备份及数据目录切换，并按分发需要完成签名与公证。 [Wails macOS 打包](https://wails.io/guides/build/macos/) · [Wails Windows 打包](https://wails.io/guides/build/windows/)
