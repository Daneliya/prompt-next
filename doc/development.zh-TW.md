# Prompt Next 開發文件

[简体中文](开发文档.md) · [English](development.en.md) · 繁體中文

## 產品與需求

Prompt Next 是以本機為主的桌面提示詞管理工具。AI 繪畫庫排在人設庫之前。目標發行平台為 macOS Apple Silicon 與 Windows x64。

| 區域 | 需求與目前行為 |
| --- | --- |
| 品牌與首頁 | 應用程式、Dock 和安裝程式使用選定的紅、藍、黃錯位照片圖示。首頁使用小房子，人設庫使用小魚，導覽圖示採用相同底色。工作台包含淺色橫幅、兩庫筆數、最近更新、儲存用量、近 14 天圖片面積圖及分類和模型圓餅圖。 |
| 瀏覽與搜尋 | 預設為卡片，首張圖片作為封面。可切換成三欄清單並保留偏好。搜尋標題、中英文正文、標籤、分類、說明、負向提示詞和模型。可篩選分類、收藏、標籤或模型，並依標題、建立或更新時間排序。 |
| 繪畫條目 | 透過對話框新增和編輯。欄位包含標題、分類、以逗號分隔的標籤、多選模型、中英文提示詞、參考圖和時間。分類與標籤各佔一列，模型下拉可搜尋並以三欄顯示。中文或英文至少填一種，說明、負向提示詞及參數放在更多欄位。 |
| 人設條目 | 獨立管理人設提示詞、標題、分類、標籤、作者、說明和時間。支援匯入舊版大肥魚人設資料。 |
| 條目操作 | 支援編輯、收藏、複製為新條目、刪除、單筆 Markdown 匯出與分別複製提示詞。雙大括號變數可先填寫和預覽。刪除顯示中文確認，離開未儲存的編輯前會提示。詳情的關閉按鈕有邊框，時間使用本機 `YYYY-MM-DD HH:mm:ss` 格式。 |
| 參考圖 | 可多選 PNG、JPEG、GIF 或 WebP。可放大預覽、拖曳排序或用左右按鈕移動，新舊圖片可混排。每筆最多 24 張，每張上限 12 MB、6400 萬像素，每次儲存的新圖片合計最多 40 MB。 |
| 偏好設定 | 左欄分為外觀、AI 模型、分類、資料管理和關於。可立即切換主題與檢視方式。兩庫各有預設及自訂分類。自訂模型可新增、修改與刪除，已儲存的模型名稱保留。資料管理可開啟資料夾、匯入及備份，關於頁提供作者的 GitHub。 |
| 備份 | 匯入預覽顯示新增、重複和無效資料。一般匯入略過重複，完整備份經確認後可覆蓋兩庫。相容舊版人設 JSON 與應用程式備份 v1、v2、v3。 |

圖片趨勢按本機檔案儲存日期計算，重複引用只計一次。還原時新寫入的圖片計入還原當天。模型圖會統計每個選取的模型。介面參考 Tiny RDM 的緊湊操作，採用小圓角及清楚的聚焦、懸停、按下和選取回饋。

## 工程分層與資料

| 路徑 | 職責 |
| --- | --- |
| `main.go` | Wails 啟動、服務註冊及資源嵌入 |
| `internal/desktop/` | Wails 介面、原生檔案對話框、剪貼簿、檔案總管 |
| `internal/library/` | 提示詞模型、SQLite、圖片、備份、設定與統計 |
| `internal/fileio/` | 共用的原子檔案寫入 |
| `frontend/src/` | Vue 介面、圖表和主題 |
| `frontend/bindings/` | 自動產生的 TypeScript 呼叫 |
| `build/` | 各平台的設定和封裝腳本 |

Go 模組名稱為 `github.com/Daneliya/prompt-next`。服務簽章變更後，可執行 `wails3 generate bindings -clean=true -ts -i` 或重新建置。前端使用 Vue 3、TypeScript、Vite 和 Naive UI。

系統使用者資料夾中的 `prompt-next` 存放 `prompts.db`、`images/<編號>/` 的各提示詞原圖及 `thumbnails/<編號>/` 縮圖。SQLite 採用 WAL 和 5 秒等候逾時，啟動時將舊自訂模型移入資料庫設定。JSON 備份 v3 包含兩庫、引用圖片、主題、檢視方式、自訂分類與模型、變數預設。復原 v1 或 v2 時保留現有設定。覆蓋前會先在 `backups/` 儲存安全快照，失敗即停止。JSON 備份上限為 128 MB，較大的圖庫可在退出程式後複製整個資料目錄。儲存庫只附合成測試樣本。

## 建置與驗收

開發執行 `wails3 dev`，產生前端資源後執行 `go test ./...`。macOS 封裝使用 `wails3 task darwin:package:dmg`，Windows x64 使用 `wails3 task windows:package ARCH=amd64`，建置環境須提供 NSIS。安裝檔位於 `bin/`。公開發行前，請在目標系統驗證安裝、WebView 首次啟動、備份還原及升級後資料保留，並依發行方式完成簽章與公證。

## 工作區與檢查

資料管理會先列出未被引用圖片的檔名、大小與縮圖。清理時重新檢查引用，24 小時內可復原的刪除紀錄也會保護圖片。多選可批次收藏、改分類、刪除或匯出。自訂分類支援更名和刪除，標籤顯示使用數量並可合併與分組瀏覽。可儲存命名的變數預設並一次複製渲染結果。原生選單可新建或搜尋，macOS 使用 Command，Windows 使用 Ctrl。正常視窗大小與位置會保存在本機。

在專案目錄執行 `wails3 task lint` 與 `wails3 task test`。CI 在 macOS 執行。「關於」及 macOS／Windows 封裝從 `build/config.yml` 的 `info.version` 讀取版本。專案已移除行動平台範本。
