# Prompt Next · 开发教程

这是一份给 Java 开发者的动手教程。现有项目已完成双库应用。想从脚手架照着课程练习时，请另建练习目录，保留现有业务代码。你会先做出能切换人设库和 AI 绘画提示词库的窗口，再把数据从 Vue 移到 Go，最后用 SQLite 保存。产品范围与接口约定见 [开发文档](开发文档.md)。

## 开始之前 · 技术选型和参考项目

### Tiny RDM 哪些地方值得参考

Tiny RDM 用 Vue 3、Vite 和 Naive UI 做界面，用 Go 和 Wails v2 做桌面应用。我们参考它的三栏工作区、紧凑列表、浅色和深色主题。自己的项目采用 Wails v3，学习时跟着 v3 文档走，因为模板、服务注册和打包命令与 v2 有区别。 [Tiny RDM 项目](https://github.com/tiny-craft/tiny-rdm) · [前端依赖](https://github.com/tiny-craft/tiny-rdm/blob/main/frontend/package.json) · [Go 依赖](https://github.com/tiny-craft/tiny-rdm/blob/main/go.mod) · [Wails v2 到 v3 迁移](https://github.com/wailsapp/wails/releases/tag/v3.0.0)

### 三种桌面方案怎么选

三个方案都可以复用 Vue 3 + TypeScript + Naive UI 的界面。区别在于页面怎么调用本地业务、你需要学哪套工具，以及怎样生成安装包。

| 方案 | Vue 如何查询数据 | 对 Java 开发者的取舍 | 发布方式 |
| --- | --- | --- | --- |
| **Wails v3 + Go（本项目）** | 调用生成的 TypeScript 方法，进入 Go 服务，查询 SQLite | 要学 Go 的结构体、错误处理和 SQL API，服务与存储的职责接近熟悉的 Java 分层 | Mac 用内置 Task 打 DMG，Windows 默认出 NSIS 安装包 |
| Tauri 2 + Rust | 通过 `invoke()` 调用 Rust 命令，也可以通过官方 SQL 插件访问 SQLite | 首版可把简单逻辑放在 TypeScript，开发和打包仍需 Rust 工具链 | Mac 出 DMG，Windows 可出 NSIS 或 MSI，官方 Action 可自动构建并上传 |
| Spring Boot + JavaFX WebView | JavaFX 窗口加载本机页面，Vue 通过 HTTP 调用 Java 服务 | 可继续用 Spring MVC 和 JDBC，需要自己衔接窗口、HTTP 服务和退出流程 | `jpackage` 将应用和 Java 运行时打成平台安装包 |

[Wails 绑定](https://v3.wails.io/features/bindings/methods/) · [Wails 打包](https://wails.io/guides/build/building/) · [Tauri 命令](https://v2.tauri.app/develop/calling-rust/) · [Tauri SQL 插件](https://v2.tauri.app/plugin/sql/) · [Tauri 自动发布](https://v2.tauri.app/distribute/pipelines/github/) · [JavaFX WebView](https://openjfx.io/javadoc/25/javafx.web/javafx/scene/web/WebView.html) · [Oracle jpackage](https://docs.oracle.com/en/java/javase/25/jpackage/packaging-overview.html)

这个项目选 Wails v3，是因为双库的查询、保存、导入和备份可以集中在本地 Go 服务里，Vue 能直接调用有类型的绑定。第一次读代码时，可以把整个流程理解为「页面 → 本地 Service → 数据库」，省去了单独编写 REST Controller 和部署服务的步骤。

| 技术 | 在本项目里做什么 |
| --- | --- |
| Vue 3 + TypeScript | 写三栏页面、切换库、管理选中状态和表单。TypeScript 为字段和函数加类型 |
| Naive UI | 提供输入框、按钮、菜单和对话框。在第 1 课通过 npm 加入项目 |
| Vite | 开发时热更新，构建时将 Vue 页面输出到 `frontend/dist` |
| Go + Wails v3 | Go 实现业务和读写，Wails 创建桌面窗口、生成绑定、构建安装包 |
| SQLite | 把两种提示词保存在本地数据库文件里。在第 3 课由 Go 驱动接入 |

## 环境安装 · Apple Silicon Mac

先检查你已有的工具。Go 需要 1.26 或更新版本，本机已验证 Go 1.27.3、Node.js 24 和 Wails v3.0.0。编辑器可继续用 IntelliJ IDEA。下面的两种安装路径可以按工具选择，有可用版本就跳过对应安装步骤。 [Wails 安装要求](https://v3.wails.io/quick-start/installation/) · [Vite 环境要求](https://vite.dev/guide/)

```bash
uname -m
xcode-select -p
git --version
go version
node --version
npm --version
wails3 version
```

`uname -m` 显示 `arm64` 代表 Apple Silicon。若 `xcode-select -p` 找不到开发工具，运行 `xcode-select --install`，按 macOS 弹窗安装 Xcode Command Line Tools。装好后再执行 `xcode-select -p` 确认。 [Wails macOS 依赖](https://v3.wails.io/getting-started/installation/)

### 路径 A · 用 Homebrew 命令安装

适合 Homebrew 下载正常的环境。运行 `brew --version` 确认已有 Homebrew，需要哪个工具就执行对应一行。 [Homebrew 官网](https://brew.sh/) · [Node.js 24 公式](https://formulae.brew.sh/formula/node%4024)

```bash
brew install go
brew install node@24
```

若新装了 `node@24` 且终端找不到 `node`，把 `export PATH="$(brew --prefix node@24)/bin:$PATH"` 加到 `~/.zshrc`，再新开终端。已有 nvm 管理的 Node.js 24 时，可以继续用它。

如果 `brew install go` 报 `Failed to upgrade Homebrew Portable Ruby`，说明 Homebrew 在下载自己的运行依赖时失败。本机遇到的是阿里云镜像返回 404，回退 GitHub 下载又中断。可以直接改走下面的官方安装包路线。

### 路径 B · 自己从官网下载安装包

这是本机后来正式安装 Go 的方式。它适合想双击安装，或者 Homebrew 下载遇到故障的情况。

1. 打开 Go 官网下载页，选 **Apple macOS (ARM64)**，下载后缀为 `darwin-arm64.pkg` 的安装包。本机安装的是 `go1.27.3.darwin-arm64.pkg`。在 Finder 的「下载」中双击安装。 [Go 下载页](https://go.dev/dl/) · [Go 安装说明](https://go.dev/doc/install)
2. Node.js 如果缺失，到 Node.js 官网选 **24 LTS**、**macOS**、**ARM64**，下载 `.pkg` 安装。npm 会随 Node.js 安装。本机已有通过 nvm 安装的 Node.js 24，这一步可以跳过。 [Node.js 下载页](https://nodejs.org/en/download)
3. 安装后关闭并重新打开终端。分别执行 `go version`、`node --version` 和 `npm --version` 确认命令可用。

### 两条路径共用 · 安装 Wails CLI

Go 安装成功后，按项目使用的版本安装 Wails。下面两条安装命令选一条即可。默认模块代理连接超时时，可以使用此前在本机验证可达的代理。这个设置仅作用于该次命令。 [Wails CLI 官方安装](https://v3.wails.io/quick-start/installation/)

```bash
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
```

```bash
GOPROXY=https://goproxy.cn go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
```

安装后在终端执行下面三行。第一行让当前终端找到 `wails3`，后两行确认版本和系统依赖。

```bash
export PATH="$(go env GOPATH)/bin:$PATH"
wails3 version
wails3 doctor
```

要让新开的终端也能找到 Wails，用文本编辑器打开 `~/.zshrc`，把上面的 `export PATH=...` 整行加到末尾。若 `go env GOBIN` 输出了自定义路径，使用那个目录。当前机器的正式安装位置是 `/usr/local/go/bin/go` 和 `~/go/bin/wails3`。

**验收**。新开终端后，`go version`、`node --version`、`npm --version` 和 `wails3 version` 都能输出版本。本机开发 Mac 版时，`wails3 doctor` 中的 Windows NSIS 和移动端 SDK 可以留到对应平台需要时再装。

### 常见问题

- **安装 Go 后仍然显示 `command not found`**。如果 `/usr/local/go/bin/go version` 有输出，说明 Go 已安装。先重新打开终端，若仍找不到，将 `export PATH="/usr/local/go/bin:$PATH"` 加到 `~/.zshrc`，放在 Wails 路径设置之前。
- **Go 能运行，Wails 找不到**。用 `ls -l "$(go env GOPATH)/bin/wails3"` 查看默认位置是否已有 CLI。有文件就检查 `PATH`，没有文件就检查 `go install` 是否成功。使用自定义 `GOBIN` 时检查对应目录。
- **终端启动时提示 OpenClaw 补全文件不存在**。这是 `~/.zshrc` 中的另一个配置问题。用 `command -v go` 和 `command -v wails3` 单独确认两个命令的路径。

## 第 1 课 · 先做一个能切换双库的三栏界面

**改哪里**。在项目根目录运行下面的安装命令。它会更新 `frontend/package.json` 和锁文件，随后在开发窗口中验证。

```bash
npm --prefix frontend install naive-ui --registry=https://registry.npmjs.org
```

打开 [App.vue](../frontend/src/App.vue)，用下面的练习代码替换模板内容。有自己的改动时，可以先保存一份再替换。

```vue
<script setup lang="ts">
import { computed, ref } from 'vue'
import { NButton, NInput } from 'naive-ui'

type Kind = 'persona' | 'art'
type Prompt = { id: string; kind: Kind; title: string; body: string }

const prompts = ref<Prompt[]>([
  { id: '1', kind: 'persona', title: '客服助手', body: '用简洁、礼貌的语气回答问题。' },
  { id: '2', kind: 'art', title: '雨夜街景', body: '霓虹灯、湿润路面、电影感构图。' },
])

const kind = ref<Kind>('persona')
const query = ref('')
const selectedId = ref<string | null>(null)

const results = computed(() => {
  const keyword = query.value.trim().toLowerCase()
  return prompts.value.filter((item) =>
    item.kind === kind.value &&
    [item.title, item.body].some((text) => text.toLowerCase().includes(keyword))
  )
})

const selected = computed(() =>
  results.value.find((item) => item.id === selectedId.value)
)

function switchLibrary(next: Kind) {
  kind.value = next
  query.value = ''
  selectedId.value = null
}
</script>

<template>
  <main class="workspace">
    <nav aria-label="提示词库">
      <h2>提示词库</h2>
      <p><NButton @click="switchLibrary('persona')">大肥鱼人设库</NButton></p>
      <p><NButton @click="switchLibrary('art')">AI 绘画提示词库</NButton></p>
    </nav>
    <section aria-label="搜索结果">
      <h2>{{ kind === 'persona' ? '人设' : '绘画' }}</h2>
      <NInput v-model:value="query" placeholder="搜索标题或正文" />
      <p v-for="item in results" :key="item.id">
        <NButton text @click="selectedId = item.id">{{ item.title }}</NButton>
      </p>
      <p v-if="results.length === 0">没有匹配记录</p>
    </section>
    <section aria-label="提示词详情">
      <h2>{{ selected?.title ?? '请选择一条提示词' }}</h2>
      <p>{{ selected?.body }}</p>
    </section>
  </main>
</template>

<style scoped>
.workspace {
  display: grid;
  grid-template-columns: 180px minmax(210px, 1fr) minmax(0, 2fr);
  gap: 20px;
  padding: 24px;
  text-align: left;
}
</style>
```

如果文字或背景还带着问候模板的样式，检查练习工程的 `index.html` 是否仍引用了模板的 `public/style.css`。布局验证完成后，再逐步把分类导航、结果列表和编辑区拆成组件。

**这一步学什么**。`ref` 保存当前库、搜索词和选中项。`computed` 类似一个随依赖变化重新计算的 getter。`v-model:value` 把输入框和搜索词连起来，`v-for` 渲染结果，`@click` 接收点击事件。

**验收**。人设库搜索「客服」，点击「客服助手」后右栏显示正文。切换到绘画库，搜索「雨夜」能打开另一条记录。返回人设库时，搜索框和选中项清空。

## 第 2 课 · 让 Vue 调用 Go 服务

若使用独立的练习目录，先看模板的 `greetservice.go` 和 `frontend/src/components/HelloWorld.vue`。修改 Go 返回的问候语并观察结果。现有正式项目可对照 [桌面接口](../internal/desktop/service.go) 和 [App.vue](../frontend/src/App.vue) 阅读实际调用链。

1. 在项目根目录新增 `promptservice.go`，使用 `package main`。定义下面的 DTO 和服务方法，先用内存数据练习。
2. 打开 [main.go](../main.go)，在 `Services` 列表追加 `application.NewService(&PromptService{})`。保存后观察终端输出，确认 Wails 重新生成绑定。必要时停止并重跑 `wails3 dev`。
3. 在 `App.vue` 顶部加入 `import { PromptService } from '../bindings/changeme'`，再把 `onMounted` 加进 Vue 的导入。将样例数组换成 `ref<Prompt[]>([])`，并用下面的加载逻辑填充它。

```go
package main

type Prompt struct {
    ID    string `json:"id"`
    Kind  string `json:"kind"`
    Title string `json:"title"`
    Body  string `json:"body"`
}

type PromptService struct{}

func (s *PromptService) ListPrompts() []Prompt {
    return []Prompt{
        {ID: "1", Kind: "persona", Title: "客服助手", Body: "用简洁、礼貌的语气回答问题。"},
        {ID: "2", Kind: "art", Title: "雨夜街景", Body: "霓虹灯、湿润路面、电影感构图。"},
    }
}
```

```ts
onMounted(async () => {
  try {
    const items = await PromptService.ListPrompts() ?? []
    prompts.value = items.filter(
      (item): item is Prompt => item.kind === 'persona' || item.kind === 'art'
    )
  } catch (error) {
    console.error('加载提示词失败', error)
  }
})
```

练习模板默认可能使用 `changeme` 模块名。正式项目使用 `github.com/Daneliya/prompt-next`，应以实际生成的 `frontend/bindings/` 路径为准。Go 方法名首字母大写可导出，JSON 标签决定前端字段名。Vue 调用时用 `await` 等待结果。 [Wails 服务绑定](https://v3.wails.io/features/bindings/methods/)

**验收**。改一下 Go 返回的绘画标题，重启或等待 Go 重编译，确认桌面里显示新标题。这一步之后，页面只负责展示数据，示例记录来自 Go。

## 第 3 课 · 用 SQLite 保存第一条数据

从一个最小的「查询、编辑、保存」流程开始，再补分类、标签、收藏和绘画专属字段。这里的步骤是后续实现练习，完整数据约定在 [开发文档](开发文档.md)。

1. 在项目根目录执行 `go get modernc.org/sqlite` 添加驱动。把连接和 SQL 放在新文件 `promptstore.go`，导入 `database/sql` 和 `_ "modernc.org/sqlite"`。这个下划线导入会注册名为 `sqlite` 的驱动。若默认 Go 模块代理超时，可对当前命令临时加 `GOPROXY=https://goproxy.cn`。 [SQLite Go 驱动](https://pkg.go.dev/modernc.org/sqlite)
2. 用 `os.UserConfigDir()` 找到系统用户配置目录，在其下创建 `prompt-next` 目录，用 `sql.Open("sqlite", dbPath)` 打开 `prompts.db`。随后调用 `Ping` 或执行建表语句检查连接。先建包含 `id`、`kind`、`title`、`body` 和 `updated_at` 的表。
3. 启动时把数据库交给 `PromptService`，退出时关闭连接。把 `ListPrompts` 改成查询 SQLite。Go 的 `*sql.DB` 类似 JDBC 的数据库访问入口，`Query` 对应查询，`Scan` 把结果列读进结构体。
4. 给右栏加标题和正文输入框，以及「保存」按钮。Go 侧实现 `SavePrompt`，校验数据，再用参数化 SQL 写入。第一次只做编辑也可以，先通过初始化数据准备一条人设和一条绘画记录。保存成功后重新读取记录，失败时保留编辑内容并提示原因。
5. 按 [开发文档](开发文档.md) 加入绘画专属字段和数据库版本迁移。先走通旧人设 JSON 的预览、导入和备份恢复，再做批量或更复杂的功能。

搜索移到 Go 后，可以先用 `WHERE kind = ? AND (instr(title, ?) > 0 OR instr(body, ?) > 0)`。把库类型和关键词作为参数传入，空搜索词单独按库查询。用真实中文提示词验证匹配范围。

**验收**。分别改一条人设和一条绘画记录，关闭应用再启动，检查两个库里的修改都保留。重复导入同一份旧人设备份，已有编辑依然保留。

## 第 5 课 · 阅读和验证已完成的工作台

1. 在 [App.vue](../frontend/src/App.vue) 搜索 `changeTheme`。设置面板的单选项调用 `PromptService.SetTheme`，保存成功后更新 Vue 的 `theme`。接着看 `isDark` 如何根据系统设置计算当前主题。
2. 在 [library/service.go](../internal/library/service.go) 查看 `SetTheme` 和 `GetTheme`，对应 SQLite 的设置读写。重新打开应用时，`onMounted` 会读取已保存的主题。
3. 在 [library/backup.go](../internal/library/backup.go) 对照 `PreviewImport` 和 `ImportPrompts`。先看旧人设字段如何映射，再看导入事务如何避免部分写入。可在项目根目录运行 `go test -v ./...`，查看重复导入和恢复的测试结果。
4. 实际试用时先从「设置」切换主题，关闭再打开确认保留。然后用顶部「导入 JSON」选旧人设备份。新建一条绘画提示词，写入一个 `{{风格}}` 变量，保存后填写并复制。最后导出一份双库 JSON 备份，验证导入预览能识别它。
